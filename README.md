\# The Drop – (2D Courier Delivery Game)



A 2D grid based courier delivery game built using C++ and SFML 3.1 in which there is a 12x16 2D array city map.



\## Group Members \& Work Distribution

\* \*\*Ahmad\*\* – SFML 3.1 event loop (`main.cpp`), game states (`game.hpp`), Visual Studio \& GitHub setup.

\* \*\*Suleman\*\* – 2D city map array, keyboard movement, and tile collision logic (`game.cpp`).

\* \*\*Ashar\*\* – Random package/destination spawning, timer \& scoring rules, HUD rendering, and documentation.



\## Controls

\* \*\*W / A / S / D\*\* or \*\*Arrow Keys\*\*: Move the courier

\* \*\*R\*\*: Restart the game



\## How to Build \& Run

1\. Open `TheDrop.slnx` in \*\*MS Visual Studio\*\*.

2\. Set configuration to \*\*`Debug`\*\* and platform to \*\*`x64`\*\*.

3\. Press \*\*`F5`\*\* to compile and run.
